# Binary Tree App

Это приватный сайт-фундамент с бинарным маркетинг-планом. 
Предназначен для хранения структуры пользователей, начислений и визуализации дерева.

## Функционал
- Хранение логинов пользователей.
- Визуализация бинарной структуры.
- История начислений.

## Технологии
- Node.js
- Express
- GitHub (хранение)
- Render (деплой)

Вот краткий отчет того, что мы уже реализовали:

1. **Выбор стека технологий:** Мы выбрали **Node.js (JavaScript)** — это профессиональный инструмент для создания веб-сайтов, который позволяет серверной и клиентской частям работать как единое целое.
2. **Развертывание (Деплой):** Мы настроили автоматическую публикацию твоего сайта через **Render** и **GitHub**. Теперь сайт доступен в сети по постоянной ссылке.
3. **Архитектура проекта:** Мы сделали «как у больших» — разделили логику на правильные файлы:
* `index.js`: серверная часть (фундамент).
* `index.html`: структура страницы.
* `style.css`: внешний вид (дизайн).
* `script.js`: логика обработки данных.
* `data.json`: база данных (иерархия участников).


4. **Мобильная адаптация:** Мы учли, что ты работаешь с телефона. Весь интерфейс настроен под мобильные экраны («Mobile First»): крупные кнопки, удобные отступы и вертикальная ориентация.
5. **Визуализация дерева:** Мы настроили отображение бинарной структуры на 3 уровня вниз (7 ячеек), которая автоматически считывает данные из JSON-файла и распределяет участников по местам.

**Итог:** У тебя есть работающий сайт, который **визуально показывает структуру бинарного маркетинга**. Ты видишь «Admin», «L1», «R1» и пустые «рамки» для будущих участников.
