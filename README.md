# Binary Tree App

Это приватный сайт-фундамент с бинарным маркетинг-планом. 
Предназначен для хранения структуры пользователей, начислений и визуализации дерева.

## Функционал
- Хранение логинов пользователей.
- Визуализация бинарной структуры.
- История начислений.

## Технологии
- Node.js
- Express
- GitHub (хранение)
- Render (деплой)
